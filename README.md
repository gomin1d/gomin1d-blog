# gomin1d

Мій особистий сайт зі статтями, нотатками та іншими матеріалами.

Сайт доступний за адресою: **[gomin1d.top](https://gomin1d.top)**

## Discourse

Основна частина матеріалів була перенесена з мого форуму на Discourse. Разом зі
статтями збережені дати їх публікації, вкладення та старі коментарі.

Нові коментарі до статей працюють через GitHub Discussions за допомогою
[Giscus](https://giscus.app).

## Технології

- [Astro](https://astro.build)
- [Tailwind CSS](https://tailwindcss.com)
- [Giscus](https://giscus.app)
- Cloudflare Workers

## Локальний запуск

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```
